# Telegram-бот для дневника

Бот для упрощения ведения дневника с возможностью отслеживания настроения, сна, энергии и визуализации изменений во времени.

## Возможности

- 📝 Добавление записи с оценками настроения, сна, энергии и заметкой
- 📊 Просмотр записей за последние 7 дней
- 📈 График изменения настроения
- 😴 График сона и энергии за 30 дней

## Установка

1. Клонируйте репозиторий или скопируйте файлы
2. Установите зависимости:
```bash
pip install -r requirements.txt
```
3. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен
4. Скопируйте `.env.example` в `.env` и вставьте токен:
```bash
cp .env.example .env
```
5. Запустите бота:
```bash
python main.py
```

## Структура проекта

```
diary/
├── config.py          # Конфигурация
├── db.py              # Работа с SQLite
├── main.py            # Точка входа
├── handlers/          # Обработчики команд
│   └── diary.py
├── utils/             # Утилиты
│   └── visuals.py     # Визуализация графиков
├── assets/            # Сгенерированные графики
└── requirements.txt
```

## Расширение

- **Новые метрики**: добавьте поля в `db.py` и обработчики в `handlers/diary.py`
- **Новые графики**: добавьте методы в `utils/visuals.py`
- **Уведомления**: можно добавить APScheduler для напоминаний
- **Категории/теги**: уже поддерживаются в БД

## Требования

- Python 3.8+
- Telegram Bot API токен

## Новое: белок, Docker

- Оценка белка при добавлении приёма пищи (по ключевым продуктам из `config.PROTEIN_TABLE`, можно расширить)
- Норма белка в `PROTEIN_TARGET_G` (.env)
- График белка по дням: зелёный >= норма, оранжевый < норма
- Docker: данные БД в volume `/data` (сохраняются при перезапуске/обновлении образа)

### Запуск в Docker

```bash
cp .env.example .env
# отредактировать .env (токен, чат, норма белка)
docker compose up -d --build
```

БД будет в `./data/diary.db`, графики в `./assets/`
