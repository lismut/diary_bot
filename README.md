# Спортивный дневник - Telegram Bot

Телеграм-бот для ведения спортивного дневника с аналитикой, графиками и автоматическим постингом в отчетный чат по топикам.

## Возможности

- Ввод данных за выбранный день с возможностью редактирования
- Отслеживание сна (время пробуждения/засыпания, качество)
- Вес тела
- Тренировки, упражнения, веса
- Скалодром: трассы, категории сложности, попытки
- Висы на зацепках
- Шаги
- Питание с расчетом белка
- Ежедневные рутины/добавки (галочки)
- Аналитика и графики по дням/неделям/месяцам/годам
- Автопостинг в форум-чат по темам (топикам)
- Логирование истории в отдельный отчетный чат
- Конфигурация через .env

## Структура

```
src/
├── bot/          # Основной код бота
├── handlers/     # Обработчики команд и диалогов
├── db/           # Модели и работа с БД
├── services/     # Сервисы (графики, расчеты, постинг)
├── utils/        # Утилиты
config/           # Конфигурация
docker/           # Docker файлы
docs/             # Документация
scripts/          # Скрипты деплоя
```
