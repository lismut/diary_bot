# Спортивный дневник — Telegram-бот

Бот ведёт спортивный дневник: записывай данные **кнопками** (или текстом),
бот считает метрики, строит графики и складывает историю и аналитику
в отдельный чат-форум по топикам.

## Как это работает

Внизу — постоянная клавиатура с разделами:

```
😴 Сон · ⚖️ Вес · 💪 Тренировка · 🧗 Лазание
🤸 Висы · 🍽 Питание · 💊 Добавки · 👟 Шаги
📋 Сводка дня · 📊 Статистика · 📤 В отчёт · 📅 День
```

- **😴 Сон** — пробуждение, засыпание (длительность считается), качество 1–10.
- **⚖️ Вес** — утренний вес.
- **💪 Тренировка** — упражнения и бассейн.
- **🧗 Лазание** — категории (6a…7c), трассы, попытки, флеш/перепролаз.
- **🤸 Висы** — размер зацепки и отягощение.
- **🍽 Питание** — быстрые продукты или свой текст, белок считается сам.
- **💊 Добавки** — креатин, коллаген и рутины: просто нажми, чтобы отметить (тумблер).
- **👟 Шаги**.
- **📋 Сводка дня · 📊 Статистика · 📤 В отчёт · 📅 День** — просмотр и выгрузка.

Каждый ввод сохраняется за **активный день** и сразу раскладывается в отчётный
чат по темам. Пропущенные дни легко дополнить: **📅 День** → «Другая дата»
(или `/day 05.11`) и вводи данные за тот день.

### Свободный ввод (запасной вариант)

Можно и просто писать строки — бот распознаёт их и сохраняет за активный день:

```
7:30                     → пробуждение
Сон 7/10                 → качество сна
78.1                     → вес
Сон 00:30                → время засыпания
Творог 250г, кешью 20г   → еда (считается белок)
Велик 30мин, Лфк с лентой→ тренировка
5 6а, 4 6б, 6с флеш      → скалодром
Висы 10мм 10кг 5х10/50   → висы на зацепках
Шаги 15к                 → шаги
Креатин, коллаген        → добавки/рутины
Басс 1 час               → бассейн
Настроение 8/10          → настроение
Пульс 55                 → пульс покоя
Вода 2л                  → вода
```

## Возможности

- Кнопочное меню: разделы ввода и просмотра, свободный текст — как запасной вариант
- Дополнение и редактирование пропущенных дней (`/day`, `/log`, `/del`, `/undo`)
- Сон: засыпание/пробуждение (длительность считается), качество 1–10
- Вес, шаги, пульс покоя, настроение, самочувствие, вода, алкоголь
- Тренировки, упражнения, веса (бассейн — как тренировка)
- Скалодром: категории, попытки, флеш/перепролаз
- Висы на зацепках: размер, отягощение, протокол, время
- Питание с автоматическим расчётом белка (база продуктов в `config/foods.json`)
- Добавки и рутины (креатин, коллаген и т.д.) — тумблеры и контроль регулярности
- Графики: вес, сон, белок (зелёный/жёлтый), шаги, лазание, висы, регулярность
- Периоды: неделя / месяц / год / всё время
- Автопостинг истории и аналитики в чат-форум по топикам
- Разовая выгрузка истории при первом запуске (без дублей при перезапуске)
- Ежедневный автоотчёт и недельная аналитика по расписанию
- Хранение данных в SQLite (или PostgreSQL), сохраняется между перезапусками

## Быстрый старт

```bash
cp .env.example .env      # вписать BOT_TOKEN
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
python run.py
```

Настроить чаты и топики: команда `/get_chat_info` (см. `docs/DEPLOYMENT.md`).

## Импорт существующего дневника

```bash
python scripts/import_diary.py diary            # импорт (пропуская дни, что уже есть)
python scripts/import_diary.py diary --reset    # очистить базу и залить заново
python scripts/import_diary.py diary --dry-run  # посмотреть разбор без сохранения
python scripts/import_diary.py diary --year 2025
```

## Команды

| Команда | Описание |
|---|---|
| `/menu` | показать кнопочное меню |
| `/help` | справка и примеры строк |
| `/cancel` | отменить пошаговый ввод |
| `/day [дата]` | показать/сменить активный день |
| `/today` | вернуться к сегодня |
| `/log` | строки активного дня |
| `/del N` | удалить строку №N |
| `/undo` | удалить последнюю строку |
| `/view [дата]` | сводка за день |
| `/last` | последние дни с записями |
| `/stats` | графики и аналитика |
| `/report` | отправить сводку дня в отчётный чат |
| `/publish [period]` | графики в отчётный чат |
| `/get_chat_info` | ID чата и топика |

## Структура

```
src/
├── bot/main.py          # запуск, планировщик, разовая выгрузка истории
├── config.py            # настройки из .env
├── db/                  # модели и CRUD
├── services/
│   ├── parser.py        # разбор строк и хелперы для кнопок
│   ├── charts.py        # графики
│   ├── reporter.py      # постинг в отчётный чат по топикам
│   └── importer.py      # импорт дневника из файла
├── handlers/
│   ├── start.py         # /start, /help, /get_chat_info
│   ├── menu.py          # главное меню: сводка, статистика, отчёт, день
│   ├── entry.py         # кнопочный ввод (сон, вес, тренировка, …)
│   ├── fallback.py      # свободный ввод строк
│   ├── common.py        # клавиатура, активный день, применение записей
│   ├── log.py, view.py, stats.py
│   └── states.py        # FSM-состояния
└── utils/
config/
├── foods.json           # продукты и белок на 100 г
└── routines.json        # добавки и рутины
scripts/import_diary.py
docs/DEPLOYMENT.md
```

Деплой и запуск: см. [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md).
